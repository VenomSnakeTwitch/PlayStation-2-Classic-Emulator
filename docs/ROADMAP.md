# Zurückgestellte Funktionen

Steam Rich Presence mit einer dynamischen Anzeige des aktuell laufenden PS2-Spiels bleibt vorerst zurückgestellt. Die derzeitige Steam-Integration öffnet Steams Hinzufügen-Fenster für eine Steam-fremde Launcher-Verknüpfung. Die Voraussetzungen einer offiziellen Steamworks-Anbindung werden getrennt behandelt.
