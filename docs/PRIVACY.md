# Veröffentlichung ohne persönliche Konsolendaten

Der veröffentlichte Quellstand wird über eine ausdrückliche Dateiliste aufgebaut. Die portable Anwendung enthält eine bereinigte Erststart-Konfiguration. Nicht veröffentlicht werden lokale Spiele, BIOS-Dateien, Memory Cards, Savestates, Benutzerprofile, eigene Handbücher und Notizen, Coversammlungen, Sicherungen, Logdateien oder Update-Zwischenstände.

Die `.gitignore` schützt die entsprechenden Laufzeitverzeichnisse auch bei späteren Änderungen. Persönliche Daten niemals mit `git add --force` hinzufügen. Fertige ZIP-Pakete werden separat als Release-Downloads bereitgestellt.
